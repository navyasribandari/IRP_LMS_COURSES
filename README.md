# IRP LMS - HTML and CSS Website

A responsive three-page front-end website that recreates the IRP LMS learning platform using only HTML and CSS. It was built as an HTML and CSS assignment for the Web Development Foundations course.

## Live Demo

- Live site:https://irplmsproject.vercel.app
- GitHub repository: https://github.com/navyasribandari/IRP_LMS_COURSES.git

## Pages

- **Home (index.html):** navigation bar, hero banner with an Explore Courses button, and a five-step Learning Journey (Learn, Practice, Build Projects, Prepare, Get Placed).
- **Courses (courses.html):** banner, a grid of 9 video tutorial cards (HTML, CSS, JavaScript, React, Python, Java, Spring Boot, Hibernate, Django) and an Explore More Courses bar.
- **Contact Us (contact.html):** contact details panel (email, phone, office address) and a message form with name, email, subject dropdown and message box.

## Features

- Same navbar, colors and fonts on all pages, with the active page highlighted
- Colors defined once using CSS custom properties (`:root`)
- Layouts built with Flexbox and CSS Grid
- Responsive for desktop, tablet and mobile using media queries
- Reusable CSS classes and clean, readable code
- No JavaScript, backend or database needed

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, media queries, custom properties)

## How to Run

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` with the Live Server extension (or in any browser).
